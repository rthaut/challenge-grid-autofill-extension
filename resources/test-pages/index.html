Challenge Grid Autofill test pages

Serve this folder with npx serve resources/test-pages so the extension can inject into the pages without file URL access. Each page says which grid from resources/test-grids to import and what to expect, and checks the fields when you submit (or when the extension auto-submits).

The pages also run as automated tests: npm run test:unit.
